1

30초 요약 — 어떻게 돌아가나요?

이 시스템의 전체 흐름은 아래 3단계가 전부입니다.

1
PD님이 시트에 작성 구글 시트에 제목·본문·발송일시를 한 줄씩 입력합니다. 미리 써두면 대기열에 쌓입니다.
2
시트 불러오기 관리자 화면에서 시트 불러오기 버튼을 누르면(또는 자동 발송이 켜져 있으면 매 분 자동으로) 목록에 반영됩니다.
3
예약 시각에 자동 발송 발송일시가 되면 구독자 전원에게 메일이 나가고, 발송 기록에 결과가 남습니다.
💡 핵심은 "콘텐츠는 시트에, 상태 확인은 관리자 화면에서"입니다. 시트의 내용이 곧 메일이 되므로, 시트만 잘 관리하면 됩니다.
2

시작하기 전, 3가지만 기억하세요

① 관리자 화면 주소

아래 주소로 접속합니다 (배포 주소에 맞게 공유해 드립니다).

https://[서비스 주소]          ← 관리자 화면 (홈)
https://[서비스 주소]/settings   ← 설정
https://[서비스 주소]/subscribers ← 구독자 관리
https://[서비스 주소]/logs       ← 발송 기록

※ 로컬 테스트 중이라면 http://localhost:3000 입니다.

② 콘텐츠 시트 (공유 링크)

PD님이 작성하시는 구글 스프레드시트입니다. 아래 링크를 즐겨찾기에 등록해 주세요.

https://docs.google.com/spreadsheets/d/1CavwYt1DHE91E1m41gf1TzCDd48HroP0D8YXTgOlsjM/edit
⚠️ 시트 공유 설정은 반드시 "링크가 있는 모든 사용자 → 뷰어" 상태를 유지해야 합니다. 시트가 비공개로 바뀌면 시스템이 시트를 읽지 못해 발송이 중단됩니다. (공유 버튼을 눌러 확인)

③ 자동 발송 스위치

관리자 화면 홈 좌측 상단의 자동 발송 켜기/끄기가 이 시스템의 마스터 스위치입니다.

  • ● 켜짐 — 매 분마다 시트를 확인하고, 발송 시각이 된 콘텐츠를 자동으로 보냅니다.
  • ○ 꺼짐 — 아무리 시각이 지나도 자동으로 보내지 않습니다. 긴급 정지 버튼으로 생각하시면 됩니다.
✅ 실수로 잘못 보낼 위험이 느껴질 때는 언제든 자동 발송을 끄고 확인 후 다시 켜면 됩니다. 발송은 끄는 즉시 멈춥니다.
3

구글 시트에 콘텐츠 작성하기

🎯 PD님 업무 · 가장 중요한 장입니다

메일 1통 = 시트 1줄입니다. 시트 첫 행은 머리글(변경 금지)이고, 2행부터 한 줄에 메일 1통씩 작성합니다.

3-1. 시트의 7개 열 규칙

열 이름필수 여부설명
발송일시선택 이 시각(한국 시간)에 발송됩니다. 2026-10-05 09:00 같은 형식을 권장합니다. 비우면 "대기열"에 들어가 설정된 기본 요일·시간마다 위에서부터 1통씩 자동 발송됩니다. (자세한 건 3-2)
제목필수 메일 제목입니다. 제목이 비어 있는 행은 무시됩니다. 제목이나 발송일시를 바꾸면 "새 콘텐츠"로 인식되어 다시 발송 대상이 됩니다.
본문선택 메일 본문입니다. 시트 셀 안에서 Ctrl+Enter(줄바꿈)으로 문단을 나눌 수 있고, **중요**처럼 양쪽에 별표 2개를 붙이면 굵게 표시됩니다.
링크선택 "바로가기" 버튼으로 들어갈 URL입니다. (예: 아티클, 이벤트 페이지)
이미지선택 메일 상단에 들어갈 배너 이미지 URL입니다. 가로 600px 이상, 2MB 이하 권장. https://로 시작하는 공개 URL이어야 합니다.
수신자선택 비우면 구독자 전원에게 발송. 특정인에게만 보내려면 이메일을 쉼표로 나열 (예: a@x.com, b@y.com).
사용선택 발송 여부 스위치입니다. 비워두거나 Y면 발송, N·X·보류·중지 등을 쓰면 발송하지 않습니다. (자세한 건 3-5)

3-2. 작성 예시 — 실제 시트 모습

발송일시제목본문링크이미지수신자사용
2026-10-05 09:00 {{이름}}님, 10월 소식입니다 안녕하세요! 이번 달 업데이트를 전해드립니다. https://example.com/news (비움) (비움 → 전체) Y
(비움 → 대기열) 주간 팁 #1 **굵게** 표시와 줄바꿈이 적용됩니다. https://example.com/tips https://…/banner.png (비움 → 전체) Y
(비움) 임원 보고용 시안 아직 작성 중인 초안입니다. ceo@company.com 보류

※ 첫 행(머리글)의 열 이름과 순서는 절대 바꾸지 마세요.

3-3. 발송일시 작성법 — "지정 발송"과 "대기열"

구분작성법동작
지정 발송
예약됨		 발송일시에 날짜·시간 입력
2026-10-05 09:00		 그 시각에 정확히 1통 발송. 날짜만 쓰면(2026-10-05) 설정된 기본 발송 시간에 보냅니다.
대기열
대기		 발송일시를 비움 미리 써둔 콘텐츠가 순서대로 쌓이고, 설정된 발송 요일·기본 시간마다 시트 위에서부터 1통씩 자동 발송됩니다. "매주 월·목 아침 9시에 하나씩" 같은 정기 발송에 사용합니다.
✅ 추천 운영법 — 이벤트성 공지는 발송일시를 직접 지정하고, 정기 뉴스레터는 날짜 없이 쭉 써두면 대기열이 알아서 순서대로 나갑니다. 두 방식을 한 시트에서 섞어 쓸 수 있습니다.

3-4. 받는 사람 지정과 개인화

  • 전체 발송(기본) — 수신자 열을 비워두면 구독자 전원에게 보냅니다.
  • 일부 발송 — 수신자 열에 이메일을 쉼표로 나열하면 그 사람들에게만 갑니다. 구독자가 아니어도 직접 입력한 주소로는 발송됩니다. (수신거부한 사람은 제외)
  • 개인화 — 제목·본문에 {{이름}}을 쓰면 수신자별 이름으로 치환됩니다. {{이름}}님, 10월 소식입니다 → "홍길동님, 10월 소식입니다". 이름이 없는 구독자는 이메일 아이디로 표시됩니다.
📧 모든 메일 하단에는 수신거부 링크가 자동으로 붙습니다. 수신거부한 사람은 다시는 발송 대상에 포함되지 않습니다(법적 필수 사항).

3-5. 임시 보류 — 아직 보내면 안 되는 콘텐츠

사용 열에 아래 중 아무거나 쓰면 그 행은 발송되지 않습니다.

N X 보류 중지 제외 미사용

초안을 미리 써두고 싶을 때 사용 열에 "보류"라고 적어두면 안전합니다. 발송하려면 "보류"를 지우거나 Y로 바꾸면 됩니다.

3-6. ⚠️ 반드시 지켜야 할 주의사항

🚨 쉼표가 들어간 제목은 한 셀에 넣어주세요. 예전에 CSV를 통째로 붙여넣는 방식으로 작성하면 {{이름}}님, 10월 소식입니다처럼 쉼표 때문에 셀이 한 칸씩 밀려 "뒤의 값은 읽지 않습니다" 경고가 뜹니다. 시트에서는 각 항목을 반드시 한 셀씩 입력하세요.
  • 첫 행 머리글(발송일시 · 제목 · 본문 · 링크 · 이미지 · 수신자 · 사용)은 이름·순서 모두 변경 금지.
  • 한 번 발송된 행은 자동으로 재발송되지 않습니다. 다시 보내려면 제목이나 발송일시를 바꿔 "새 콘텐츠"로 만들거나, 관리자 화면에서 수동 재발송합니다.
  • 발송 직전에 행을 수정하면 매분 다시 읽히므로 반영됩니다. 단, 발송 중(sending) 상태일 때는 기다려 주세요.
  • 시트 공유가 "링크가 있는 모든 사용자 – 뷰어"인지 수시로 확인 (2번 항목 참고).
  • 이미지는 구글 드라이브 공유 링크가 아닌, https로 접근되는 공개 이미지 URL을 사용해야 메일에 정상 표시됩니다.
4

관리자 화면 사용법

🧑‍💼 대표님 · PD님 공통

관리자 화면은 홈 / 구독자 / 발송 기록 / 설정 4개 메뉴로 구성됩니다. 상단 내비게이션으로 이동합니다.

4-1. 홈 — 현황판과 발송 제어

접속하면 가장 먼저 보이는 화면입니다. 상단 4개 카드로 전체 상황을 파악합니다.

카드보는 방법
자동 발송● 켜짐 / ○ 꺼짐. 우측 켜기끄기 버튼으로 제어. 아래에 스케줄러가 "정상 동작 중"인지 표시됩니다.
다음 발송다음에 나갈 메일의 시각과 제목. "예정 없음"이면 보낼 콘텐츠가 없다는 뜻.
활성 구독자현재 메일을 받는 구독자 수. 수신거부한 사람은 자동 제외된 수치입니다.
발송 방식메일 서버 상태. 테스트 모드라고 노란색으로 표시되면 실제 메일이 나가지 않는 상태입니다 (6장 FAQ 참고). 아래에는 기본 발송 요일·시간이 표시됩니다.

시트 불러오기 / 스케줄러 실행 버튼

🔄 시트 불러오기 시트 내용을 지금 즉시 반영합니다. 시트를 수정한 뒤 "제대로 반영됐나?" 확인할 때 누르세요.

⏱ 스케줄러 지금 실행 자동 발송을 기다리지 않고 지금 즉시 스케줄러를 돌립니다. 발송일시가 지난 콘텐츠가 있으면 즉시 나갑니다.

💡 자동 발송이 켜져 있으면 매 분 자동으로 시트를 다시 읽기 때문에, 평소에는 버튼을 누르지 않아도 됩니다. 버튼은 "지금 바로 확인하고 싶을 때" 쓰는 기능입니다.

콘텐츠 목록의 상태 표시

상태의미
대기대기열에 있음. 설정된 요일·시간에 순서대로 발송됩니다.
예약됨발송일시가 지정되어 대기 중. 그 시각에 자동 발송.
발송 중지금 메일이 나가는 중. 잠시만 기다려 주세요.
발송 완료발송됨. 몇 명에게 갔는지 아래에 표시됩니다.
실패발송 실패. 항목 아래에 빨간색 오류 내용이 표시되므로 개발 담당자에게 공유해 주세요.
기한 지남발송일시가 지났는데 자동 발송이 꺼져 있거나 서버가 멈춰 있던 상태. 켜면 다음 확인 시점에 발송됩니다.
보류시트의 "사용" 열이 N/보류 등이라 발송 제외된 상태.

행마다 있는 작업 버튼

버튼동작
미리보기실제 메일 모양을 새 탭에서 확인합니다. 발송 전 반드시 확인 권장.
테스트설정에 등록된 테스트 수신 이메일 1명에게만 시험 발송합니다. 구독자에게는 안 갑니다.
지금 발송예약을 기다리지 않고 전체 구독자에게 즉시 발송. 누르면 "n명에게 발송할까요?" 확인 창이 뜹니다.
재발송이미 보낸 콘텐츠를 다시 보냅니다. (발송 완료된 행에 표시)
대기로발송 완료/실패 상태를 대기로 되돌립니다. 실수로 보낸 뒤 재정비해서 다시 보낼 때 사용.

4-2. 구독자 — 받는 사람 관리

  • 구독자 추가 — 왼쪽 입력창에 한 줄에 한 명씩 hong@example.com, 홍길동 또는 홍길동 <hong@example.com> 형식으로 붙여넣고 추가합니다. 여러 명을 한 번에 붙여넣을 수 있습니다.
  • 시트에서 구독자 불러오기 — 구글 시트에 '이메일', '이름' 두 열로 된 구독자 탭을 만들어두면, 동기화 버튼으로 명단을 한 번에 가져올 수 있습니다. 수신거부한 사람은 동기화해도 다시 살아나지 않습니다.
  • 목록 — 이메일, 이름, 출처(직접입력/시트), 등록일, 상태(활성/수신거부) 확인. 행별로 활성 토글·삭제 가능.

4-3. 발송 기록 — 무엇이 언제 누구에게 갔나

모든 발송이 건 단위로 자동 기록됩니다. 시각 · 제목 · 수신자 · 결과(성공/실패) · 발송 방식이 남습니다.

  • 대표님 보고용으로 "언제 무엇을 몇 명에게 보냈는지"의 근거 자료로 사용할 수 있습니다.
  • 실패 건은 오류 메시지가 함께 표시됩니다. (예: 잘못된 이메일 주소)

4-4. 설정 — 발송 규칙 변경

항목설명
콘텐츠 스프레드시트 URLPD님이 작성하는 시트의 주소. 특정 탭을 쓰려면 그 탭을 연 상태의 URL(gid 포함)을 넣습니다.
구독자 시트 URL (선택)'이메일', '이름' 열이 있는 구독자 탭의 URL.
기본 발송 시간대기열 콘텐츠와 "날짜만" 쓴 콘텐츠가 나가는 시간 (예: 09:00).
대기열 발송 요일대기열이 몇 요일에 발송될지 선택. 예: 월·목 선택 → 매주 월·목 아침에 1통씩.
보내는 사람 이름수신자에게 표시되는 발신자 이름.
테스트 수신 이메일테스트 버튼을 누를 때 메일을 받을 주소. 반드시 1개 등록 권장.
서비스 주소수신거부 링크에 쓰일 주소. 비워두면 자동 설정됩니다.

수정 후 설정 저장을 누르면 즉시 반영됩니다. 설정 화면 우측에는 메일 서버(Gmail/Resend)와 스케줄러 안내가 있습니다 — 이 부분은 개발 담당자 영역이니 건드리지 않아도 됩니다.

🎯 PD님 · 발송 직전 1분 점검
  • 시트 첫 행 머리글(발송일시 · 제목 · 본문 · 링크 · 이미지 · 수신자 · 사용)이 그대로 있는가?
  • 보낼 행의 제목이 비어 있지 않은가? (비어 있으면 그 행은 발송되지 않음)
  • 발송일시가 올바른가? — 지정 발송은 날짜+시간, 정기 콘텐츠는 비움(대기열)
  • 당장 보내면 안 되는 행의 사용 열에 "보류" 또는 N이 적혀 있는가?
  • 수신자 열 확인 — 비어 있으면 구독자 전원에게 발송됨을 인지했는가?
  • 제목·본문의 {{이름}} 치환이 의도대로인가? 링크·이미지 URL이 https로 정상 접속되는가?
  • 관리자 화면에서 해당 행의 미리보기로 메일 모양을 확인했는가?
  • 가능하면 테스트 발송으로 본인 메일함에서 최종 확인했는가?
  • 홈 화면의 자동 발송이 켜져 있고, 발송 방식이 "테스트 모드"가 아닌가?

자주 묻는 질문 (FAQ)

시트에 썼는데 목록에 안 나타나요.
홈 화면에서 🔄 시트 불러오기를 눌러보세요. 오류 메시지가 뜨면 ① 시트 공유가 "링크가 있는 모든 사용자 – 뷰어"인지, ② 첫 행 머리글이 그대로인지, ③ 제목 열이 비어 있지 않은지 확인해 주세요.
"테스트 모드"라고 뜨는데 괜찮나요? (대표님 꼭 확인)
메일 서버가 아직 연결되지 않은 상태입니다. 이때는 발송 기록만 남고 실제 메일은 발송되지 않습니다. 실제 발송을 시작하려면 개발 담당자가 Gmail(SMTP) 또는 Resend 설정을 완료해야 합니다. 실제 오픈 전에는 반드시 "발송 방식" 카드에 테스트 모드가 아닌 Gmail/Resend가 표시되는지 확인하세요.
실수로 메일이 나갔어요. 멈출 수 있나요?
홈 화면에서 자동 발송 끄기를 누르면 즉시 정지됩니다. 이미 나간 메일은 회수할 수 없지만, 재발송 방지 로직 덕분에 같은 콘텐츠가 두 번 나가지는 않습니다. 잘못 나간 행은 "대기로" 버튼으로 상태를 되돌린 뒤 수정·재발송할 수 있습니다.
한 번 보낸 콘텐츠를 다시 보내고 싶어요.
두 가지 방법이 있습니다. ① 목록에서 재발송 버튼 클릭(전체 구독자에게 즉시 재발송), ② 시트에서 제목이나 발송일시를 바꾸면 새 콘텐츠로 인식되어 다시 발송 대상이 됩니다.
메일은 하루에 몇 통까지 보낼 수 있나요?
Gmail(SMTP)로 발송할 경우 하루 약 500통 제한이 있습니다. 구독자가 많아지면 개발 담당자에게 Resend 등 대량 발송 서비스 전환을 요청해 주세요. 콘텐츠 수 자체는 시트에 제한 없이 등록할 수 있습니다.
정해진 요일마다 자동으로 하나씩 나가게 하고 싶어요.
바로 대기열 기능입니다. 시트의 발송일시를 비우고 콘텐츠를 위에서부터 순서대로 쌓아두면, 설정에서 선택한 요일(예: 월·목)의 기본 시간마다 1통씩 자동 발송됩니다. "다음 발송" 카드에 다음에 나갈 메일이 표시되니 미리 확인하세요.
발송 기록에서 실패가 떠 있어요.
행 아래에 빨간색 오류 내용이 표시됩니다. 대부분 잘못된 이메일 주소이므로 구독자 목록에서 수정해 주세요. 원인을 알 수 없으면 오류 메시지를 그대로 개발 담당자에게 공유해 주세요.
수신거부는 어떻게 되나요?
모든 메일 하단에 수신거부 링크가 자동으로 붙고, 클릭하면 즉시 구독자 목록에서 "수신거부" 처리됩니다. 수신거부한 사람은 시트 동기화·재발송으로도 다시 포함되지 않습니다. (수신자 열에 직접 입력한 경우에도 제외됩니다.)
