1. 시스템 개요

이 시스템은 콘텐츠를 작성하고 구독자에게 이메일을 발송하는 관리자용 웹 애플리케이션입니다.

  • 콘텐츠 작성 및 미리보기
  • 구독자 목록 관리
  • SMTP를 이용한 메일 발송
  • 발송 로그 확인
  • 구독 해지 링크 처리
테스트 모드 안내: SMTP 설정이 정상적으로 등록되면 시스템은 테스트 provider가 아니라 SMTP를 사용합니다. 별도의 “테스트 모드 해제” 버튼은 없습니다.

2. Vercel 환경변수 설정

Vercel 프로젝트에서 Settings → Environment Variables로 이동해 아래 변수를 등록합니다.

변수명설명적용 환경
SMTP_USERSMTP 계정 이메일 주소Production and Preview
SMTP_PASSSMTP 비밀번호 또는 Gmail 앱 비밀번호Production and Preview
SMTP_HOSTSMTP 서버 주소. Gmail은 smtp.gmail.comProduction and Preview
MAIL_FROM발신자 주소Production and Preview
DATABASE_URLPostgreSQL 연결 문자열Production and Preview
SHEET_URL연동할 시트 주소가 필요한 경우 등록필요한 환경
중요: 환경변수 값을 저장한 뒤에는 반드시 Deployments → Redeploy를 실행해야 배포된 앱에 반영됩니다.

3. Gmail SMTP 설정

Google 앱 비밀번호 만들기

  1. Google 계정에서 2단계 인증을 활성화합니다.
  2. Google 계정의 앱 비밀번호 메뉴로 이동합니다.
  3. 메일 발송용 앱 비밀번호를 생성합니다.
  4. 생성된 16자리 앱 비밀번호를 SMTP_PASS에 입력합니다.
일반 Gmail 로그인 비밀번호를 SMTP_PASS에 사용하지 마세요. 값이 노출되었다면 즉시 앱 비밀번호를 폐기하고 새로 발급하세요.
550 5.4.5 Daily user sending limit exceeded: 인증 오류가 아니라 Gmail 계정의 발송 한도입니다. 앱은 동일한 실패를 반복하지 않도록 배치를 멈추고 24시간 쿨다운 후 미발송분을 이어 보냅니다. 앱의 한도 값을 높여도 Gmail 제한은 바뀌지 않습니다. 정기 대량 뉴스레터는 도메인 인증과 수신 동의를 갖춘 전용 이메일 서비스(예: Resend)를 사용하세요.

권장 값

SMTP_USER=your-account@gmail.com
SMTP_PASS=Google 앱 비밀번호 16자리
SMTP_HOST=smtp.gmail.com
MAIL_FROM=your-account@gmail.com

4. 관리자 작업 순서

  1. 콘텐츠 작성: 제목, 본문, 링크, 이미지를 입력합니다.
  2. 미리보기: 발송 전에 Preview 화면에서 HTML이 올바르게 보이는지 확인합니다.
  3. 구독자 확인: 발송 대상과 이메일 주소를 확인합니다.
  4. 발송: 발신 주소와 SMTP 연결 상태를 확인한 뒤 발송합니다.
  5. 로그 확인: 성공·실패 결과와 오류 메시지를 확인합니다.
  6. 구독 해지: 수신자가 해지 링크를 누르면 이후 발송 대상에서 제외되는지 확인합니다.

6. 문제 해결

메일이 발송되지 않음

  • Vercel 환경변수 이름이 정확한지 확인합니다.
  • SMTP_USER, SMTP_PASS가 비어 있지 않은지 확인합니다.
  • Gmail 일반 비밀번호가 아닌 앱 비밀번호를 사용했는지 확인합니다.
  • 환경변수 저장 후 Redeploy했는지 확인합니다.
  • /logs에서 실제 오류를 확인합니다.

Gmail 550 5.4.5 한도 초과

앱은 더 이상의 SMTP 시도를 중단하고 24시간 후 미발송분을 재개합니다. 그동안 반복해서 수동 발송하지 말고 /logs에서 마지막 성공 주소를 확인하세요. 앱 한도 변경은 Gmail 제공자 한도를 늘리지 않습니다. 대량 발송이 필요하면 Resend 등 전용 서비스를 설정하세요.

Server Components render 오류

브라우저에는 상세 오류가 숨겨질 수 있습니다. Vercel의 Deployments → Functions/Runtime Logs에서 실제 오류를 확인하세요. 특히 DATABASE_URL과 데이터베이스 연결 상태를 점검합니다.

로컬 설치 또는 빌드 오류

cd D:\automated-mailing-system\sheet-mailer
npm install
npm run dev

로컬 개발 화면은 http://localhost:3000에서 확인합니다. 배포 빌드 오류는 Vercel의 빌드 로그에서 먼저 확인합니다.

7. 보안 주의사항

  • SMTP_PASS, DATABASE_URL을 채팅·문서·Git에 그대로 공유하지 않습니다.
  • .env 파일을 Git에 커밋하지 않습니다.
  • 비밀번호가 노출되었다면 SMTP 앱 비밀번호를 즉시 폐기하고 재발급합니다.
  • 운영용 환경변수는 Vercel의 Production 환경에 반드시 등록합니다.
  • 발송 전 수신자 목록과 메일 내용을 반드시 검토합니다.
